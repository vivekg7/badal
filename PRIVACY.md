# Badal privacy policy

Effective 2026-11-09. Applies to Badal (`io.github.vivekg7.badal`) as
published on Google Play and in this repository.

**Badal collects no data.** It has no internet permission, so it cannot send
anything anywhere: no account, no ads, no analytics, no crash reporting, no
tracking.

## What stays on your phone

- **Pictures you add** are copied into Badal's private storage, so a gallery
  clean-up can't break an album. Badal reads only the pictures you pick in
  Android's photo picker, or the folders you choose to add or follow.
- **Designs you make** are drawn into the same storage.
- **Settings and albums** are one file in that storage.

Uninstalling Badal deletes all of it. Android's cloud backup is turned off for
Badal, because it would upload every picture copy; use Settings → Save a
backup instead, which writes one file to a place you choose and nowhere else.

## What Badal reads

- **Do Not Disturb, dark theme and charging**, on the phone only, to switch
  modes you set up. Nothing about them is stored or shared.
- **The screen turning off**, to change the picture before the next unlock.

## What Badal writes outside its storage

- **Your wallpapers**, through Android's wallpaper service.
- **Pictures you save to the gallery** (Pictures/Badal), and **backups** where
  you choose to save them.

## Permissions

| Permission                                   | Why                                                |
| -------------------------------------------- | -------------------------------------------------- |
| Set wallpaper                                | To change the home and lock screen wallpapers      |
| Run in the foreground (special use)          | To hear the screen turn off and modes' cues change |
| Schedule exact alarms (only if you allow it) | To change at the exact minute you set              |
| Run at startup                               | To restart the schedule after the phone restarts   |
